Question: What is the difference between @SpringBootApplication, @ComponentScan, @EnableAutoConfiguration, and @Import, and how do you exclude auto-configuration?

Short answer

@SpringBootApplication combines application configuration, component scanning, and auto-configuration. @ComponentScan finds application components. @EnableAutoConfiguration imports conditional framework defaults. @Import explicitly registers configuration or components. Exclude an unwanted auto-configuration through the annotation or the documented property.

Decision rule

  • Use scanning for your component packages.
  • Use import for an intentional module boundary.
  • Use auto-configuration for conditional framework defaults.
  • Exclude only when you replace the behavior or the dependency is not appropriate.

After an exclusion, verify that required replacement beans, health checks, and failure handling still exist.

I would use explicit imports for composition and exclusions as a last-mile customization, then confirm the resulting bean graph with the condition report.

Example decision

If a service needs the default MVC stack plus one custom converter, keep Boot auto-configuration and provide the converter bean. If it must replace the server or security chain, exclude only the relevant default and register the complete replacement. A broad exclusion can remove health, metrics, or infrastructure beans that other code assumes exist.

Follow-up questions

  • Where does component scanning start?
  • What happens when two configuration classes define the same bean name?
  • How do conditional beans back off for user-defined beans?

Minimal exclusion example

@SpringBootApplication(exclude = DataSourceAutoConfiguration.class)
class Application { }

Use an exclusion only when the application supplies a complete replacement or deliberately has no datasource. Verify startup, health, and metrics after the change.

Interview-ready answer

@SpringBootApplication combines configuration, component scanning, and auto-configuration. I use explicit imports for composition, exclusions sparingly, and the condition report to verify the resulting bean graph.
