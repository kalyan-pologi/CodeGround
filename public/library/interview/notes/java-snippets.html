Reusable Java stream and collector snippets, question by question.

Practical Stream API patterns worth having memorized cold for an interview, built around a simple Employee model (id, name, department, salary, gender, joiningDate, dateOfBirth).

Imports & Model

import java.time.LocalDate;
import java.time.Period;
import java.util.*;
import java.util.concurrent.CompletableFuture;
import java.util.concurrent.TimeUnit;
import java.util.function.Function;
import java.util.stream.Collectors;
import java.util.stream.Stream;

public class Employee {
    private final int id;
    private final String firstName;
    private final String lastName;
    private final String gender;
    private final String department;
    private final double salary;
    private final LocalDate joiningDate;
    private final LocalDate dateOfBirth;
    private final String email;

    public Employee(int id, String firstName, String lastName, String gender,
                     String department, double salary, LocalDate joiningDate,
                     LocalDate dateOfBirth) {
        this.id = id;
        this.firstName = firstName;
        this.lastName = lastName;
        this.gender = gender;
        this.department = department;
        this.salary = salary;
        this.joiningDate = joiningDate;
        this.dateOfBirth = dateOfBirth;
        this.email = firstName.toLowerCase() + "." + lastName.toLowerCase() + "@company.com";
    }

    public int getId() { return id; }
    public String getFirstName() { return firstName; }
    public String getLastName() { return lastName; }
    public String getFullName() { return firstName + " " + lastName; }
    public String getGender() { return gender; }
    public String getDepartment() { return department; }
    public Double getSalary() { return salary; }
    public LocalDate getJoiningDate() { return joiningDate; }
    public LocalDate getDateOfBirth() { return dateOfBirth; }
    public String getEmail() { return email; }

    public int getAge() {
        return Period.between(dateOfBirth, LocalDate.now()).getYears();
    }

    public int getYearsOfExperience() {
        return Period.between(joiningDate, LocalDate.now()).getYears();
    }

    public String getAgeCategory() {
        int age = getAge();
        if (age < 30) return "Young";
        else if (age <= 40) return "Middle";
        else return "Senior";
    }
}

Filtering & Sorting

Q: Get all IT employees, sorted by salary descending.

    .filter(e -> e.getDepartment().equals("IT"))
    .sorted(Comparator.comparing(Employee::getSalary).reversed())
    .forEach(e -> System.out.println(e.getFullName() + ": " + e.getSalary()));

Excluding Extremes Within a Group

Q: For each department, drop the highest and lowest paid employee before running any further aggregation, so a single outlier doesn't skew the numbers.

List<Employee> trimmed = employees.stream()
    .collect(Collectors.groupingBy(Employee::getDepartment))
    .values().stream()
    .flatMap(deptList -> {
        if (deptList.size() <= 2) return Stream.empty();
        return deptList.stream()
            .sorted(Comparator.comparingDouble(Employee::getSalary))
            .skip(1)
            .limit(deptList.size() - 2);
    })
    .toList();

Cross-Referencing Within a Group

Q: Find every pair of employees who share a first name but work in different departments, and report the salary gap between each pair.

Map<String, List<Employee>> byFirstName = employees.stream()
    .collect(Collectors.groupingBy(Employee::getFirstName));

byFirstName.values().stream()
    .filter(list -> list.size() > 1)
    .forEach(list -> {
        for (int i = 0; i < list.size(); i++) {
            for (int j = i + 1; j < list.size(); j++) {
                Employee e1 = list.get(i), e2 = list.get(j);
                if (!e1.getDepartment().equals(e2.getDepartment())) {
                    double diff = Math.abs(e1.getSalary() - e2.getSalary());
                    System.out.printf("%s (%s) vs %s (%s), diff: %.2f%n",
                        e1.getFullName(), e1.getDepartment(),
                        e2.getFullName(), e2.getDepartment(), diff);
                }
            }
        }
    });

CompletableFuture

The core methods for composing async work without blocking, worth knowing individually since interviews often ask "what's the difference between X and Y" for pairs like thenApply/thenApplyAsync or thenCombine/thenCompose.

Q: Run a task asynchronously and get its result later.

CompletableFuture<String> future = CompletableFuture.supplyAsync(() -> {
    sleep(1);
    return "Hello";
});

Q: Transform a future's result once it's available (thenApply runs on the same thread that completed the future, thenApplyAsync forces it onto a different thread from the pool).

CompletableFuture<String> transformed = future.thenApply(result -> result + " World");

transformed.thenApplyAsync(data -> {
    sleep(1);
    return data.toUpperCase();
}).thenAccept(result -> System.out.println("thenApplyAsync: " + result));

Q: Consume a future's result without returning anything.

transformed.thenAccept(result -> System.out.println("thenAccept: " + result));

Q: Run a follow-up action after a future completes, without needing its result.

transformed.thenRun(() -> System.out.println("thenRun: Task completed"));

Q: Combine the results of two independent futures once both are done.

CompletableFuture<String> greeting = CompletableFuture.supplyAsync(() -> "Hi");
CompletableFuture<String> name = CompletableFuture.supplyAsync(() -> "Shiva");

greeting.thenCombine(name, (g, n) -> g + ", " + n + "!")
    .thenAccept(result -> System.out.println("thenCombine: " + result));

Q: Chain one async call that depends on the result of a previous one (thenCompose flattens a future-of-a-future, thenApply would leave you with a nested one).

CompletableFuture<String> chained = greeting.thenCompose(g ->
    CompletableFuture.supplyAsync(() -> g + " again"));
chained.thenAccept(result -> System.out.println("thenCompose: " + result));

Q: Recover from an exception with a fallback value.

CompletableFuture<String> errorHandled = CompletableFuture.supplyAsync(() -> {
    throw new RuntimeException("Oops!");
}).exceptionally(ex -> {
    System.out.println("exceptionally: " + ex.getMessage());
    return "Fallback";
});

Q: Handle both the success and failure case together in one callback (unlike exceptionally, handle always runs, even on success).

CompletableFuture<String> handled = CompletableFuture.supplyAsync(() -> {
    throw new RuntimeException("Another Error");
}).handle((result, ex) -> {
    if (ex != null) return "Handled error";
    return result;
});

Q: Run a side effect regardless of whether the future succeeded or failed, without changing its result.

CompletableFuture.supplyAsync(() -> "Done")
    .whenComplete((res, ex) -> {
        if (ex == null) System.out.println("whenComplete: " + res);
    });

Q: Wait for several futures to all finish before continuing.

CompletableFuture<Void> all = CompletableFuture.allOf(greeting, name, transformed);
all.thenRun(() -> System.out.println("allOf: All tasks done"));

Q: Continue as soon as the first of several futures finishes, ignoring the rest.

CompletableFuture<Object> any = CompletableFuture.anyOf(
    CompletableFuture.supplyAsync(() -> "First"),
    CompletableFuture.supplyAsync(() -> { sleep(1); return "Second"; })
);
any.thenAccept(result -> System.out.println("anyOf: " + result));

Q: Block and get a future's result without dealing with a checked exception.

String result = transformed.join(); // like .get(), but throws unchecked on failure

Q: Utility to simulate a slow task, used by the examples above.

private static void sleep(int seconds) {
    try {
        TimeUnit.SECONDS.sleep(seconds);
    } catch (InterruptedException ignored) {}
}

Multithreading

These exercises cover the core Java concurrency tools used to create, coordinate, and safely stop work across multiple threads.

Q: Create and start a thread that prints a completion message.

Thread worker = new Thread(() -> System.out.println("Worker completed"));
worker.start();
worker.join();

Q: Run a task using the Runnable interface.

Runnable task = () -> System.out.println("Runnable executed");
Thread worker = new Thread(task);
worker.start();
worker.join();

Q: Return a value from a background task with Callable and Future.

ExecutorService executor = Executors.newSingleThreadExecutor();
Future<String> result = executor.submit(() -> "Callable result");
System.out.println(result.get());
executor.shutdown();

Q: Execute three tasks with a fixed thread pool and wait for all of them.

ExecutorService executor = Executors.newFixedThreadPool(3);
List<Future<?>> tasks = new ArrayList<>();
for (int i = 0; i < 3; i++) tasks.add(executor.submit(() -> {}));
for (Future<?> task : tasks) task.get();
System.out.println("tasks completed = " + tasks.size());
executor.shutdown();

Q: Safely increment a shared counter with a synchronized method.

class Counter {
    private int value;
    synchronized void increment() { value++; }
    synchronized int get() { return value; }
}
Counter counter = new Counter();
Thread first = new Thread(() -> { for (int i = 0; i < 100; i++) counter.increment(); });
Thread second = new Thread(() -> { for (int i = 0; i < 100; i++) counter.increment(); });
first.start(); second.start(); first.join(); second.join();
System.out.println("counter = " + counter.get());

Q: Use AtomicInteger for a lock-free counter update.

AtomicInteger counter = new AtomicInteger();
Thread first = new Thread(() -> { for (int i = 0; i < 100; i++) counter.incrementAndGet(); });
Thread second = new Thread(() -> { for (int i = 0; i < 100; i++) counter.incrementAndGet(); });
first.start(); second.start(); first.join(); second.join();
System.out.println("counter = " + counter.get());

Q: Protect a shared update with a synchronized block.

int[] counter = {0};
Object lock = new Object();
Runnable increment = () -> { for (int i = 0; i < 100; i++) synchronized (lock) { counter[0]++; } };
Thread first = new Thread(increment); Thread second = new Thread(increment);
first.start(); second.start(); first.join(); second.join();
System.out.println("counter = " + counter[0]);

Q: Use ReentrantLock to protect a critical section.

java.util.concurrent.locks.Lock lock = new java.util.concurrent.locks.ReentrantLock();
AtomicInteger counter = new AtomicInteger();
Runnable increment = () -> { for (int i = 0; i < 100; i++) { lock.lock(); try { counter.incrementAndGet(); } finally { lock.unlock(); } } };
Thread first = new Thread(increment); Thread second = new Thread(increment);
first.start(); second.start(); first.join(); second.join();
System.out.println("counter = " + counter.get());

Q: Stop a worker cooperatively using a volatile flag.

System.out.println("worker stopped");
