# CodeGround

Interview prep notes and coding practice for Java, Spring Boot, DevOps, frontend, system design, and GenAI.

- Java coding challenges and debugging questions
- ReidyAI project tasks
- Code snippets and command references

## Run

Requires Node.js 20.16+ and npm.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```
